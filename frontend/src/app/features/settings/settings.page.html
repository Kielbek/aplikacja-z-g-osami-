Jak podłączyć VoxCPM2

Na maszynie z GPU (CUDA) zainstaluj zależności modelu i uruchom serwis silnika.

  1. Zainstaluj zależnościpip install -r tts-engine/requirements-voxcpm.txt
  2. Uruchom serwis z modelemcd tts-engine && ENGINE_MODE=voxcpm2 uvicorn app.main:app --port 8808
  3. Wskaż adres backendowi (jeśli inny niż domyślny)ENGINE_URL=http://gpu-host:8808

Kliknij polecenie, aby je skopiować. Po uruchomieniu modelu fragmenty wygenerowane w trybie demo zostaną oznaczone jako nieaktualne.
